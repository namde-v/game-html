# Offline HTML games

Open any file in a browser. Each game is a single HTML document and runs fully offline — no images, fonts, or network requests.

| Game | File | How to play |
| --- | --- | --- |
| Nova Break | [games/game-002-nova-break.html](games/game-002-nova-break.html) | Neon brick breaker. Move with the mouse, a finger drag, or A/D and the arrow keys. Click, tap, or Space to launch the orb. P or Esc pauses, M mutes. Clear every prism to advance. |
